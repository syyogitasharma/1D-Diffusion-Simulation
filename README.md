
# 1D Diffusion Simulation Using Python

## Project Overview
This project was completed as part of Computational Mathematics coursework at IISc Bengaluru. It focuses on solving the one-dimensional diffusion equation using numerical methods in Python.

## Numerical Methods
- Implicit finite-difference method
- Crank–Nicolson method
- Thomas algorithm for solving tridiagonal systems
- Comparison with analytical diffusion solutions

## Python Libraries
- NumPy – Numerical computations
- Matplotlib – Visualization of concentration profiles

## Project Files
- **Diffusion_notebook (3).ipynb** – Numerical diffusion simulations and comparison of solution methods.
- **Diffusion_delta_function (1).ipynb** – Diffusion from a localized initial concentration profile.
- **Thomas_Algo.ipynb** – Tridiagonal system solver using the Thomas algorithm.

## Results
The simulations illustrate the evolution of concentration profiles with time and compare numerical results with analytical reference solutions.

## Learning Outcomes
- Understanding diffusion equations and finite-difference discretization.
- Implementing numerical methods in Python.
- Solving tridiagonal systems using the Thomas algorithm.
- Visualizing and interpreting numerical results.
